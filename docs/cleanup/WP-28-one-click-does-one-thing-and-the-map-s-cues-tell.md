# WP-28 · One click does one thing, and the map's cues tell the truth

Part of the [Atlas cleanup list](README.md) — **second pass** (2026-09-26).

**Goal:** A double click, Enter or an arrow key should do the one thing the DM aimed at, and paid generation should not start twice. Map colours, glyphs, popover stacking and the voice picker should show the real state.

**Do after:** [WP-03](WP-03-autosave-that-tells-the-truth.md), [WP-10](WP-10-sessions-clock-labels-and-the-party.md), [WP-13](WP-13-the-map-surface-canvas-tree-and-outlines.md), [WP-14](WP-14-images-backdrops-and-the-archive.md)

B125 narrows the placing and drawing keydown handlers so that a focused button keeps its Enter. B128, B126, B127 and P114 extend B032, B064 and P051 to the ambience button and the Archive; B128 also wants a server 409 while a generation runs. C104 shows a saved voice that the current provider does not list and disables Say it for it. P115 hides voice when R2 is off. B124 finishes 302d7b9's colour language on image pins, lantern and marker pins, regions and list rows — do it together with C013's placement-visibility rule (WP-10), and ask Bennett which cue wins when a node is both lit and out of time.
