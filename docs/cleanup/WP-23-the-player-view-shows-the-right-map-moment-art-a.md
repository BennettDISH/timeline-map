Part of the [Atlas cleanup list](README.md) — **second pass** (2026-09-26).

**Goal:** A player's screen should match the URL, show a moment the server allows and show the art the DM sees. A pin that offers 'go inside' should lead somewhere, and removed or regenerated ambience should stop or reset.

**Do after:** [WP-02](WP-02-protect-the-live-campaign-data-undo-clone-and-ba.md), [WP-05](WP-05-the-player-view-never-strands-a-player.md)

**Notes:** B100 adds a request guard to PlayerView's load() and openNode; its double-click-enter case reproduces with no added delay. Land it with or after WP-05, whose B009, C002, P072 and P076 fixes rewrite the same load(), and make P076's sheet refetch use B100's request counter. B101 resets the viewed moment when the refreshed world no longer allows it, and keeps a Now control whenever one is set. B102 makes walkUp and /locate try every non-DM placement; B010's reachableNode and B039's lantern walk both build on walkUp. B105 adds ORDER BY id to the clone SELECTs that B036 (WP-02) is already editing. B103: B071's snapping alone keeps the backdrop tie, so also send an order key with the windowed backdrops. B104 and C094 are ambience, which no first-pass lane could see because production has none. B106 fixes the marker form closing on a double click. Borders WP-05; kept separate because these are races and stale state rather than the dead-link screen.

Broken · medium · effort s · second pass, found by `long-session`
